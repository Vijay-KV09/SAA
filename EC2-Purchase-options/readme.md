Types of Instances
1. On-Demand Instances: Pay for compute capacity by the second or hour, with no long-term commitment.
2. Reserved: Commit to a specific instance type in a region for 1 or 3 years, and get up to 75% discount vs On-Demand.
3. Savings Plan: You commit to a certain spend ($/hour) for 1 or 3 years, and AWS automatically applies the discount to any compute usage.
4. Spot Instances: Use unused EC2 capacity at up to 90% discount, but AWS can terminate anytime when capacity is needed elsewhere.
5. Dedicated Hosts: A physical server fully dedicated to you, with full control over instance placement and licensing (BYOL).
6. Dedicated Instances: Instances that run on hardware dedicated to a single customer.
7. Capacity Reservation: Reserve capacity in a specific AZ, ensuring you can launch instances anytime.You pay for reserved capacity whether used or not.
